# ☕ Estudos de Java Básico - Loiane Groner

Este repositório contém a resolução dos exercícios e códigos práticos desenvolvidos durante o curso de **Java Básico**, ministrado pela professora **Loiane Groner**.

O objetivo deste projeto é construir e consolidar uma base sólida em lógica de programação, sintaxe da linguagem Java e boas práticas de desenvolvimento.

---

## 📌 Conteúdos Praticados

Durante o curso e a resolução das listas de exercícios, foram aplicados os seguintes conceitos:

* **Sintaxe Básica e Variáveis:** Tipos primitivos, declaração e atribuição de variáveis.
* **Entrada e Saída de Dados:** Manipulação de dados com a classe `Scanner` e exibição via `System.out.println`.
* **Operadores:** Aritméticos, relacionais, lógicos e operador de resto (`%`).
* **Funções Matemáticas:** Utilização da biblioteca `Math` (`Math.ceil`, `Math.floor`, etc.).
* **Estruturas Condicionais:** `if`, `else if`, `else` e `switch-case`.
* **Estruturas de Repetição:** `while`, `do-while` e `for`.
